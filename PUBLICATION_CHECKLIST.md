# Publication Checklist

## Content and policy

- [ ] Employer intellectual-property and external-publication approval completed.
- [ ] Maintainer identity and monitored security/conduct contact configured.
- [ ] Naming and trademark review completed for intended jurisdictions.
- [ ] No confidential, proprietary, customer, employee, or internal operational information included.
- [ ] All examples remain fictional.
- [ ] Subject and Priority are the only mandatory fields.
- [ ] Ownership remains within Subject.
- [ ] Incident and security policy precedence is explicit.
- [ ] Copyright attribution in both licences is correct.

## Repository

- [ ] Create `spin-engineering-communication` as a private repository first.
- [ ] Push the prepared main branch.
- [ ] Enable private vulnerability reporting.
- [ ] Configure branch protection and required Pages workflow checks.
- [ ] Review issue forms and community files.
- [ ] Confirm all internal links and SVGs pass validation.

## Website

- [ ] Run `python scripts/validate.py`.
- [ ] Run `mkdocs build --strict`.
- [ ] Review desktop and mobile layouts in both themes.
- [ ] Confirm code-block copy controls work.
- [ ] Set the canonical `site_url` and repository URL.
- [ ] Enable GitHub Pages with **GitHub Actions** as the source.
- [ ] Approve and run the deployment workflow.

## Articles

- [ ] Add the final public repository and documentation URLs.
- [ ] Complete editorial and employer publication review.
- [ ] Publish manually to LinkedIn and Medium only after approval.
- [ ] Record publication dates and links in the changelog or project site.
