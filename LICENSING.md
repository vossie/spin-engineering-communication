# Licensing Recommendation

## Recommended split

- **CC BY 4.0:** specification, documentation, examples, templates, articles, and original SVG artwork.
- **MIT:** website JavaScript, validation scripts, and GitHub workflow code.

CC BY 4.0 permits sharing and adaptation, including commercial use, provided users give appropriate credit, link to the licence, and identify changes. MIT permits broad reuse of software while requiring preservation of its copyright and permission notice.

The licences are scoped in the repository README and file notices. Neither licence grants trademark rights. They do not establish exclusive ownership of “S.P.I.N.” or its acronym.

## Before public release

1. Replace the placeholder copyright attribution if a specific individual or organisation should be named.
2. Confirm that the publisher is authorised to license every included work.
3. Complete employer intellectual-property and external-publication review.
4. Obtain legal advice if trademark protection or formal name clearance is required.

This repository provides a practical licensing recommendation, not legal advice.
