# Security Policy

S.P.I.N. is primarily documentation and a static website, but security issues may still occur in workflows, dependencies, or examples.

Do not disclose a suspected vulnerability in a public issue. Use GitHub private vulnerability reporting after the repository is published, or the private maintainer contact listed in the repository profile.

Never include credentials, tokens, real incident evidence, personal data, or sensitive configuration in examples or reports.

S.P.I.N. does not replace an organisation's security incident process. Report suspected security incidents through the established security channel immediately, even when impact is not yet known.
